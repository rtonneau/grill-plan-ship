# grill-plan-ship design sources

Editable sources for the images on `main`. They live on this branch so the plugin itself ships only PNGs: the Claude plugin directory holds every SVG in a plugin for review, because an SVG can carry script.

| Source | Rendered to (on `main`) |
|---|---|
| `docs/icon.svg`, generated by `tools/gen_icon.py` | `docs/icon.png`, 512×512, transparent: the plugin's listing icon (`plugin.json` → `icon`) |
| `docs/gps-workflow.svg`, edited by hand | `docs/gps-workflow.png`, 2400×2520 (1.5×), transparent corners: the README diagram |

## Re-render

Needs Python 3, Node.js and Playwright with Chromium (`npm i playwright`; adjust `executablePath` in the scripts if your Chromium lives elsewhere).

```bash
# icon: edit tools/gen_icon.py (layout, sizes, colours), then
python3 tools/gen_icon.py docs/icon.svg
node tools/render-icon.js docs/icon.svg icon.png preview.png    # preview.png: 112, 48 and 24 px

# diagram: edit docs/gps-workflow.svg (bump the version in its <title> and heading), then
node tools/render-diagram.js docs/gps-workflow.svg gps-workflow.png
```

Copy the PNGs to `docs/` on a branch from `main`, and commit the source change here.
